PT / VT Ratio & Injection

Nominal ratio = Vprimary / Vsecondary. Expected secondary = Injection / ratio. Ratio error = (Measured − Expected) / Expected × 100.

CT Ratio, Secondary & Injection

Expected CT secondary = Primary test current × CT secondary / CT primary. Relay injection current = CT secondary input × selected multiple.

Relay Pickup / FLC / Setting

3-phase FLC ≈ kW×1000 / (√3×V×PF×η). Primary pickup = FLC × setting %. Relay secondary pickup = primary pickup × CT secondary / CT primary.

Transformer Differential Reference

For 3-phase transformer current: I = MVA×1000/(√3×kV). This tool gives reference currents; actual differential compensation depends on relay vector group, CT connections and relay configuration.
